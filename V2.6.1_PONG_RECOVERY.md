# v2.6.1 resident Pong recovery patch

- Resumes an existing Rook Zero -> Volt Runner Pong challenge instead of creating duplicates.
- Reads durable `paid_challenger` / `paid_challenged` flags before each paid call, preventing a cron retry from charging a side twice.
- If Rook already paid, the next eligible Director tick pays only Volt Runner, then starts the match.
- Persists challenge_id + match_id in Director actions and records an explicit both-paid/match-missing state.
- Keeps the Durable Object alarm as the authoritative Pong simulator/replay generator.
- Fixes the mobile Open Challenges row to use five columns and wrap safely.
- Does not change x402 facilitator, prices, daily caps, free discovery, MCP surface, or identity/reputation rules.
