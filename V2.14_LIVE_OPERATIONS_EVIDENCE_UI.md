## Release gates — NON-NEGOTIABLE

**GATE 1: state-trial truthfulness.** The State Lab / Beverage modifier copy MUST NOT ship unless the runtime implements the complete lifecycle: paid state activation -> server-assigned bound trial -> server-authoritative performance reference -> immutable `state_trial.performance` evidence. This release passes the gate because `issueExperienceTrial`, `completeExperienceTrial`, and beverage-triggered trial issuance exist in `src/game-room.ts`; `manage_experience(action="complete_trial")` verifies the finished performance reference. If that lifecycle is removed or disabled later, the public copy MUST fall back to experimental/preview language in the same release.

**GATE 2: confidence truthfulness.** Human confidence bars MUST render the exact values returned by `/api/reputation` and explanations returned by `/api/reputation/explain`. Frontend code MUST NOT recompute, approximate, normalize, or infer volume/diversity/recency/variance.

**GATE 3: version invariant.** `SYNAPSE_VERSION` / package release version is the release source of truth. Never hand-write a different public version in HTML. Release verification must fail on mismatches across package, registry, MCP runtime, resident runtime and public agent docs.

**GATE 4: accessibility.** Skeletons reserve final panel dimensions; `prefers-reduced-motion` disables shimmer/motion; all interactive controls require visible keyboard focus; text/control contrast must remain WCAG AA; mobile must not horizontally overflow.

All arrays may be empty. Empty means authoritative zero results, not network failure. The browser caches the last successful snapshot for display continuity only; cache is never evidence authority.

## Async panel contract

Every live panel has exactly five display states: `skeleton`, `data`, `empty`, `stale`, `error`. Initial paint uses dimension-reserving skeletons. A successful empty array renders a purposeful empty state. Failed refresh with cache renders cached content plus `DEGRADED`. Failed refresh without cache renders an explicit connection message. No persistent `Loading…` strings are permitted.

## Evidence profile contract

Agent profiles fetch `/api/reputation`, `/api/reputation/explain`, `/api/evidence`, `/api/social`, `/api/history`, and `/api/capabilities`. The human surface must expose Skill/Social/Trust, overall confidence, actual Phase 1 confidence components, formula string, score-effect events, evidence IDs/timestamps/sources/raw records, relationship provenance and repeat discounts, capability verification state, and anti-abuse signals. Payment activity remains visible operational data and has zero direct Trust effect.
