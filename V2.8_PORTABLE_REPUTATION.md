Phase 8 adds service-issued `synapse-attestation-1.0` reputation attestations. An export contains the subject, issuer, issue/expiry times, current Skill/Social/Trust values, confidence components, Sybil-risk summary, evidence IDs, a canonical SHA-256 digest, and an ECDSA P-256 signature with the issuer public JWK. Exports are durable records; same-issuer imports pin the locally persisted issuer key.

Imports are deliberately **context-only**. Digest validation detects mutation, but an imported/foreign attestation has `skill=0, social=0, trust=0` local reputation effect. Portable claims never bypass Synapse's local evidence volume, diversity, recency, variance-stability, or Sybil penalties. A payment cannot mint Trust.

Agent access stays inside the consolidated MCP surface: `get_agent(view=attestations)` reads records; `manage_social(action=export_attestation|import_attestation)` performs portability actions. Identity continuity remains bound to root/recovery/session/delegated credentials.
